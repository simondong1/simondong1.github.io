How Flash Attention Speeds Up And by how much

Attention waits on HBM. Keep scores in registers and that wait goes away.

Where this kernel is used

Default softmax kernel in PyTorch SDPA, vLLM, SGLang — Qwen3, Llama, Gemma, and other GQA models. Not linear attention.

3.The tile walk

A block keeps a query tile on-chip and walks key/value tiles. Scores exist for one tile, then they are gone.

query tile
key tiles →

Filled = scores that exist right now. Dashed = already folded into the running output.

running max
running sum
running output

Each tile updates those three, then the scores are gone. Later tiles can still merge: rescale by the new max, then add.

Mental model

Speedup is HBM trips, not FLOPs. Hopper and Blackwell only change the multiplier for the same walk.
